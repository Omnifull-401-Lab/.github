# Welcome to Omnifull-401-Lab

**Omnifull-401-Lab** is an undergraduate **Electronic Information Engineering** student team focused on **Embedded Systems (Hardware & Software)**, **Computer Vision**, and **Intelligent Robotics**.

Together, we design circuits, write firmware and vision algorithms, and compete in major engineering contests—including **Embedded Systems Design Competitions (嵌入式芯片与系统设计竞赛)** and **National Undergraduate Electronics Design Contests (全国大学生电子设计竞赛 / NUEDC)**.

## Core Collaboration Principles

1. **Simplified GitHub Flow**: Keep `main` always stable and runnable—create short-lived branches (`feat/`, `fix/`, `docs/`, `hw/`) and merge via Pull Requests.
2. **Review Before Merge**: Member PRs require at least one review approval before merging; administrators may merge after self-checking `Files changed`.
3. **Coordinate Binary & Hardware Edits**: Announce in the team chat or an Issue before editing schematics, PCBs, or Keil/CubeMX project files to avoid unmergeable conflicts.
4. **Clean Paths & Clean Repos**: Use pure ASCII paths without spaces, apply our standard [`.gitignore`](https://github.com/Omnifull-401-Lab/team-handbook/blob/main/.gitignore), and package firmware binaries or Gerber/BOM bundles in GitHub `Releases`.
5. **Zero Secrets in Git**: Never commit Wi-Fi passwords, API keys, private keys, or files larger than 100 MB.
